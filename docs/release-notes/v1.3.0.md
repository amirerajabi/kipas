Kipas 1.3 can type your logins for you, like KeePass's auto-type.

Installed copies update themselves (Settings → Updates → Check for updates).

### Downloads

- **Windows:** `Kipas-Setup-1.3.0.exe`
- **macOS (Apple silicon):** `Kipas-1.3.0-mac-arm64.dmg`
- **Linux:** `Kipas-1.3.0-x86_64.AppImage`

### New

- **Auto-type (Windows):** select an item and press **Ctrl+V**. Kipas steps aside and types into the window you were in
  before: by default the user name, Tab, then the password. It also works from the quick-access window (Ctrl+V there
  types into the app underneath).
- **Your own sequence, for all items or one:** set the default in Settings → General → Auto-type, or give an item its
  own in Edit → Auto-type. Buttons insert the pieces, so `{USERNAME}{TAB}{TAB}{PASSWORD}{ENTER}` (or `{TAB 2}`) takes a
  few clicks. `{TOTP}` types the current one-time code, `{DELAY 500}` waits, `{S:PIN}` types a custom field.
- Passwords are typed as characters, so the keyboard layout (Persian, German, ...) does not change what is typed.
  Kipas waits for you to let go of Ctrl, and stops if another window comes to the front while it types.
- KeePass imports keep each entry's auto-type sequence.
- **Ctrl+B** copies the user name and **Ctrl+C** the password, as before.

On macOS and Linux, auto-type is not available yet; Ctrl+V says so.

The builds are not code-signed yet. On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On
macOS, right-click the app and choose **Open** the first time.
