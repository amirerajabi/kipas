The first release of Kipas, a modern, friendly password manager in the spirit of KeePass, for Windows, macOS and Linux.
Your passwords live in one encrypted file on your device: no account, no cloud, no tracking.

### Downloads

- **Windows:** `Kipas-Setup-1.0.0.exe`
- **macOS (Apple silicon):** `Kipas-1.0.0-mac-arm64.dmg`
- **Linux:** `Kipas-1.0.0-x86_64.AppImage`

The builds are not code-signed yet. On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On
macOS, right-click the app and choose **Open** the first time.

### Highlights

- Vaults are `.kipas` files, encrypted with AES-256-GCM and a key from PBKDF2-SHA256 (600 000 rounds). Saves are atomic,
  and the previous version is kept as `.kipas.bak`.
- Logins, cards, secure notes and Wi-Fi networks, with hidden custom fields, tags, favourites, groups and a trash.
- Two-factor codes built in: paste the setup key or `otpauth://` link and Kipas shows the live code.
- Password and passphrase generator, and a strength meter everywhere you type a password.
- Password health: weak, reused and old passwords, and websites without two-factor, checked on your device only.
- Copied secrets are wiped from the clipboard after 20 seconds; the vault locks after 5 idle minutes and when the
  computer locks or sleeps.
- Password history per entry, so an accidental change can be undone.
- Import CSV from KeePass, KeePassXC, Bitwarden, 1Password, LastPass, Chrome, Edge and Firefox; export to CSV.
- Command palette (Ctrl+K; Ctrl+Enter copies a result's password), KeePass shortcuts (Ctrl+B, Ctrl+C, Ctrl+U), light and
  dark themes.
- Automatic updates from GitHub Releases: on Windows and Linux new versions download in the background and install with
  **Restart to update**. On macOS the app shows the new version with a link. Only the version information is fetched;
  your vault never leaves your device.
