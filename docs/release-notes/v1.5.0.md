Kipas 1.5.0 can start automatically when you sign in to Windows.

Installed copies update themselves (Settings → Updates → Check for updates).

### Downloads

- **Windows:** `Kipas-Setup-1.5.0.exe`
- **macOS (Apple silicon):** `Kipas-1.5.0-mac-arm64.dmg`
- **Linux:** `Kipas-1.5.0-x86_64.AppImage`

### New

- **Start with Windows:** turn on **Start Kipas when Windows starts** in **Settings → General → Startup**. It is off
  by default. Kipas opens when you sign in, and your vault stays locked until you unlock it. Turn it off in the same
  place to remove it from startup. The switch reflects changes made in Windows Task Manager or Startup settings too.
  This option is available in the packaged Windows app.

The builds are not code-signed yet. On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On
macOS, right-click the app and choose **Open** the first time.
