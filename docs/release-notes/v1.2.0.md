Kipas 1.2 has a lighter, cleaner look and a quick way to grab a password from any app.

Installed copies update themselves (Settings → Updates → Check for updates).

### Downloads

- **Windows:** `Kipas-Setup-1.2.0.exe`
- **macOS (Apple silicon):** `Kipas-1.2.0-mac-arm64.dmg`
- **Linux:** `Kipas-1.2.0-x86_64.AppImage`

### New

- **A new layout in three columns:** your vault on the left, the items in the middle, and the selected item on the
  right. The toolbar and status bar are gone.
  - Each item is a roomy row; hover it to copy the user name or password in one click.
  - Every field in the details has its own Copy button.
  - Sort by name, recently changed, recently added or user name, and add any kind of item from the **+** button.
  - Saving, the clipboard countdown, updates and the auto-lock timer sit quietly at the bottom of the side panel,
    next to a **Lock** button.
- **Quick access:** press **Ctrl+Shift+Space** (Cmd+Shift+Space on macOS) in any app, type a few letters and press
  **Enter** to copy the password. **Ctrl+B** copies the user name, **Ctrl+T** the one-time code, **Ctrl+U** opens the
  site. The vault stays in the main window; the quick window only sees names. You can turn it off in Settings → General.
- **Password health is now a page** (Ctrl+H): a score, and one card per problem with the items to fix.

The builds are not code-signed yet. On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On
macOS, right-click the app and choose **Open** the first time.
