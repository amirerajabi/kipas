Kipas 1.1 brings your KeePass passwords over in one step.

Installed copies update themselves (Settings → Updates → Check for updates).

### Downloads

- **Windows:** `Kipas-Setup-1.1.0.exe`
- **macOS (Apple silicon):** `Kipas-1.1.0-mac-arm64.dmg`
- **Linux:** `Kipas-1.1.0-x86_64.AppImage`

### New

- **Import from KeePass.** Open a `.kdbx` database from KeePass 2, KeePassXC, KeeWeb or Strongbox directly, with its
  master password and key file (menu → Vault → Import from KeePass, or Settings → Import & export). Everything comes
  along: entries, nested groups, custom fields (hidden ones stay hidden), tags, two-factor secrets, password history, and
  the recycle bin, which lands in Kipas's trash. Your KeePass file is not changed.
- Works with KDBX 3.1 and 4.x, AES-KDF and Argon2 (d and id), AES and ChaCha20, and every kind of key file.
- Not supported: databases encrypted with Twofish (switch them to AES or ChaCha20 in KeePass first) and KeePass 1.x
  `.kdb` files (save them as `.kdbx` in KeePass 2). Attachments are counted but not imported yet.

Unlocking a KeePass database is slow on purpose, so the import shows a progress bar while it works.

The builds are not code-signed yet. On Windows, SmartScreen may warn on first run: choose **More info → Run anyway**. On
macOS, right-click the app and choose **Open** the first time.
